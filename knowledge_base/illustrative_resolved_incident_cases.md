# Illustrative resolved incident references

**Provenance:** This is a synthetic POC library. Its 22 examples are not real Progressive incidents, verified historical tickets, or production resolutions. The `illustrative_resolved` status means each sample contains a representative resolution workflow; it does not claim an actual incident occurred.

The assignment guide retrieves one case by issue category and symptom terms, then presents its stored three-step workflow and any documented watch-out. The guide does not use the live incident snapshot as evidence of successful resolution. Validate every check against current data and approved runbooks. Table names in examples are drawn from the project’s documented Workers’ Compensation knowledge base; no undocumented EDW table names are assumed.
